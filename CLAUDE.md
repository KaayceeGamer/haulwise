# Working on Haulwise

- Releases go out only when the owner says "push" (1-2 a day, changes batched).
- With every push, update `docs/CURSEFORGE.md` (the CurseForge project description) to match
  what's new, and send it to the owner to paste in: CurseForge's API can't change the description.
  The "New in" line at the top only covers the release just uploaded (no older versions:
  those are in the changelog). Also keep `CHANGELOG.md` and the guide's news lines (`Guide.lua`) current.
